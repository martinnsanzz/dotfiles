 SHORTCUTS  (Option = ⌥)                    q closes this

 TABS
   Option+1..9        go to tab 1..9
   Option+c           new claude tab (pick a project)
   Option+d           open a project in VS Code (pick one)
   Option+e           file tree popup (yazi), current folder
                      enter open, → into folder, ← back
   Option+t           new shell tab
   Option+r           rename tab
   Option+x           close tab (not home or calendar)

 PANES
   Option+arrows      move left/down/up/right
   Option+Shift+arrows   resize
   Option+z           zoom pane to full tab (toggle)
   Option+v           split side by side
   Option+s           split top/bottom
   Option+w           close pane

 SCROLLING / COPY
   Option+u           scroll up into history
   j/k  Ctrl+u/d      move / page in history
   v then y           select, copy to clipboard
   q                  back to normal

 CALENDAR (tab 2, Option+2)
   ←↓↑→ / hjkl        move the selected day
   n / p   N / P      next / prev page, next / prev year
   m  w  d  y         month, week, day, year view
   t   g              today, go to a date (2027-03-14)
   a / Enter          add an event on the selected day
   tab  j/k           choose one of the day's events
   e / x              edit / delete it (asks y/n)
   form: tab next field, space all day, enter save, esc
   form: leave Ends empty (or N/A) for no end time
   mouse              click day, double-click adds
   ?                  every calendar key

 TO-DO LIST (calendar tab, bottom right)
   j/k  g/G           move, first / last
   a   e / Enter      add, edit (Text, Due, Flag)
   space   f          done / not done, flag
   x / Delete         delete (asks y/n)
   form: due = tom, fri, 14, 25/11 or 2027-03-14

 HOME TAB APPS / SERVICES (procs pane focused)
   j/k  tab           move, switch apps ⇄ services
   x                  force quit (asks y/n)
   t                  quit gently
   s  /  a            sort, filter, services of all users

 HOME TAB ART (art pane focused)
   n / p              next / previous animation
   space              pause
   k                  hide / show the shortcuts box
   q                  quit to shell (type home-art to restart)

 YAZI (file tree, Option+e)
   j/k  h/l           down/up, parent/enter folder
   Enter              open file in vim (in the popup)
   q                  close the tree
   (hover)            preview the file in the right column
   a  r  d            create, rename, trash
   Space  y  x  p     select, copy, cut, paste
   .                  show/hide hidden files

 VIM
   i  Esc             type / stop typing
   :w  :q  :wq        save, close, save and close

 OTHER
   Option+/           this list
   Ctrl+b r           reload tmux config
   Ctrl+b d           detach (session keeps running)
   Cmd+Shift+r        reload Ghostty config
