 SHORTCUTS  (Option = ⌥)                    q closes this

 TABS
   Option+1..9        go to tab 1..9
   Option+c           new claude tab (pick a project)
   Option+d           new developer tab (pick a project)
                      enter open, → into folder, ← back
   Option+t           new shell tab
   Option+r           rename tab
   Option+x           close tab (home can't be closed)

 PANES
   Option+arrows      move left/down/up/right
   Option+Shift+arrows   resize
   Option+z           zoom pane to full tab (toggle)
   Option+v           split side by side
   Option+s           split top/bottom
   Option+w           close pane

 SCROLLING / COPY
   Option+u           scroll up into history
   j/k  Ctrl+u/d      move / page in history
   v then y           select, copy to clipboard
   q                  back to normal

 HOME TAB APPS / SERVICES (procs pane focused)
   j/k  tab           move, switch apps ⇄ services
   x                  force quit (asks y/n)
   t                  quit gently
   s  /  a            sort, filter, services of all users

 HOME TAB ART (art pane focused)
   n / p              next / previous animation
   space              pause
   k                  hide / show the shortcuts box
   q                  quit to shell (type home-art to restart)

 YAZI (file tree)
   j/k  h/l           down/up, parent/enter folder
   Enter              open file in nvim
   (hover)            preview the file in the right column
   a  r  d            create, rename, trash
   Space  y  x  p     select, copy, cut, paste
   .                  show/hide hidden files

 NVIM
   Option+n           every nvim shortcut
   Space (in nvim)    shows what can follow
   i  Esc             type / stop typing
   Ctrl+s  :q         save, close

 OTHER
   Option+/           this list
   Option+n           nvim shortcuts
   Ctrl+b r           reload tmux config
   Ctrl+b d           detach (session keeps running)
   Cmd+Shift+r        reload Ghostty config
